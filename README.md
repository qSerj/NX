# CAD для начинающих

Учебный проект для начинающих пользователей, в том числе детей: учимся придумывать, моделировать и собирать собственные конструкции в CAD. Исходные материалы разрабатываются для **Siemens NX 2212 с классическим Sketch**; общая основа отделена от блоков действий в конкретной программе, следующий вариант — Fusion 360. Материалы рассчитаны на возможность публичной публикации на GitHub.

Сквозной проект — условный танк по мотивам Pz. IV. Начинаем с башни и орудия; корпус и ходовая часть — по интересу. Историческая точность не требуется. Предварительные навыки указаны в каждом уроке.

Короткие практические занятия рассчитаны ориентировочно на 10–15 минут и развивают самостоятельную работу в CAD. Для ученика предусматривается цветная памятка A5 в PDF для вклейки в блокнот; методические заметки преподавателя хранятся отдельно. Действующие условия формата и проверки материалов — в [требованиях](docs/requirements.md).

## Работа с материалами

Разделы размещены в папках с префиксами `00`–`08` в порядке курса; внутри них уроки имеют постоянные названия папок без номеров. Порядок прохождения задаёт план курса; вставка занятия не требует переименования остальных папок. Фактическая готовность материалов и результаты проверок указаны в паспортах уроков.

Первыми разрабатываются пилоты по обрезке, размерам и равенству, выбору контуров. Вводные занятия, корпуса и рёбра, поверхности, свободная форма и самостоятельные работы дополняются по плану курса.

Проект: [qSerj/NX](https://github.com/qSerj/NX). Отдельная память проекта запланирована в [qSerj/NXMemory](https://github.com/qSerj/NXMemory); устройство меморекса будет проработано отдельно.
