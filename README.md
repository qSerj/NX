# Siemens NX для начинающих

Учебный проект для начинающих пользователей, в том числе детей: учимся придумывать, моделировать и собирать собственные конструкции в **Siemens NX 2212 с классическим Sketch**. Материалы рассчитаны на возможность публичной публикации на GitHub.

Сквозной проект — условный танк по мотивам Pz. IV. Начинаем с башни и орудия; корпус и ходовая часть — по интересу. Историческая точность не требуется. Предварительные навыки указаны в каждом уроке.

Короткие практические занятия рассчитаны ориентировочно на 10–15 минут и развивают самостоятельную работу в NX. Для ученика предусматривается цветная памятка A5 в PDF для вклейки в блокнот; методические заметки преподавателя хранятся отдельно. Действующие условия формата и проверки материалов — в [требованиях](docs/requirements.md).

## Что лежит в проекте

- [Документация](docs/README.md) — исходная вводная, требования и маршрут курса.
- [Уроки](lessons/README.md) — список 24 заготовок, правила оформления и шаблон занятий.
- [План курса](docs/course-plan.md) — 24 темы и порядок разработки пилотов.

## Текущий этап

Созданы документация и заготовки всех 24 уроков по шаблону. Наполняем их постепенно, по одному. Готовых к проведению уроков, чертежей и моделей NX пока нет.

Следующий шаг — согласовать структуру курса и зависимости между уроками. Затем подготовить три пилота: свободное рисование и обрезка, размеры и равенство, выбор контуров и выдавливание. После проверки в NX 2212 и пробных занятий скорректировать методику.

Проект: [qSerj/NX](https://github.com/qSerj/NX). Отдельная память проекта запланирована в [qSerj/NXMemory](https://github.com/qSerj/NXMemory); устройство меморекса будет проработано отдельно.
