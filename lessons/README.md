# Уроки

Готовых занятий пока нет. Первые материалы разрабатываются для уроков **01, 02 и 06** после согласования структуры и зависимостей.

Для нового занятия копируем [шаблон](lesson-template.md) в каталог `NN-short-name/` под именем `lesson.md`. Номер соответствует полному курсу, а не порядку разработки пилота.

Материалы добавляем по мере появления:

```text
NN-short-name/
  lesson.md       сценарий, заметки для отца и результаты проверки
  drawings/       чертежи с размерами
  images/         исходный и ожидаемый вид
  models/         старт, запасной старт и эталон
```

Пустые каталоги всех 24 уроков заранее не создаём. У каждого фактически подготовленного файла указываем назначение в карточке занятия. Отсутствующие материалы явно отмечаем; урок с непроверенными моделями не выдаём за готовый к проведению.
