# Уроки

Созданы заготовки всех 24 уроков по шаблону. Наполняем их постепенно, по одному; готовых к проведению занятий пока нет. Первые пилоты по плану — **01, 02 и 06**. Зависимости уточняем при разработке.

Для наполнения выбираем урок из списка ниже и редактируем его `lesson.md`, ориентируясь на [шаблон](lesson-template.md) и [действующие требования](../docs/requirements.md). Номер соответствует полному курсу, а не порядку разработки пилота. Сохранившиеся упоминания конкретного ученика и отца отражают исходный контекст разработки, а не ограничение аудитории; при дальнейшей работе и перед публикацией формулировки адаптируем для ученика и преподавателя без изменения учебного замысла.

Материалы добавляем по мере появления:

```text
NN-short-name/
  lesson.md       сценарий, заметки преподавателя и результаты проверки
  drawings/       чертежи с размерами
  images/         исходный и ожидаемый вид, исходники иллюстраций
  models/         старт, запасной старт и эталон
  handout/        памятка A5 в PDF и её редактируемые исходники
```

В каждой папке урока уже есть заготовка `lesson.md`. Каталоги создаём по мере подготовки файлов. У каждого фактически подготовленного файла указываем назначение в таблице материалов урока, там же отмечаем отсутствие PDF и исходников памятки. Результаты проверок записываем в «Проверке урока»; отдельный реестр не нужен. Урок с непроверенными моделями не выдаём за готовый к проведению, а неполный комплект — за полностью готовый. Ученический PDF не включает подготовку преподавателя и внутренние записи разработки.
